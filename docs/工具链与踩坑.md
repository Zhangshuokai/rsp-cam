# 工具链与踩坑

> 结论先行：本项目 Python 侧无构建/测试/lint 工具链，不要去找；只有 `教学webppt/` 用 npm/Vite 构建。个别脚本有 pip 依赖（`paramiko`、`pyserial`，已装在用户级 Python 3.14）。
> 本文汇总散落在 `AGENTS.md` 与本项目实测中的**工具链坑**，按工具分组；环境与网络细节见 `docs/树莓派连接与部署.md`，ROS 2 / Docker 见 `docs/ROS2与micro-ROS选型.md`。

## 1. PlatformIO

- **下载慢到不可用**：`pio run` 装 `espressif32` 平台/工具链时，registry 会 302 到境外对象存储（实测 `usc1.contabostorage.com`），**单连接约 50 KB/s**（直连和走代理都慢，不是代理问题）。
- 该存储**支持 HTTP Range**，多连接线性叠加（24 连接约 1 MB/s）。用 `tools/pio_mirror_seed.py` 按 PlatformIO 的缓存命名（`sha1(镜像 Location + X-PIO-Content-SHA256)`）预取到 `~/.platformio/.cache/downloads/`，之后 `pio run` 直接命中缓存。
- PIO 的**平台/工具包可能装不全就中断**（下载 tmp 长期 0 字节），杀掉重跑即可。

```mermaid
flowchart LR
    A["pio run 装平台/工具链"] -->|registry 302| B["境外对象存储<br/>单连接 ~50 KB/s"]
    B --> C["tools/pio_mirror_seed.py<br/>多连接（24 路）预取"]
    C --> D["~/.platformio/.cache/downloads/<br/>sha1(Location+SHA256)"]
    D --> E["pio run 命中缓存 → 正常编译"]
```

## 2. micro-ROS 静态库（`micro_ros_platformio`）

- **原生 Windows 编不过**（不是配置问题）：首次构建要 POSIX shell + `colcon` 交叉编译 `libmicroros`（`. <venv>/activate`、`` `which python` ``、`install/setup.sh`），Windows `cmd` 报 `'.' is not recognized`。它**总是从源码编库**，官方没有预编译包。
- 做法：WSL 里编一次 `tools/microros_lib_wsl.sh`，产物 `libmicroros/`（`libmicroros.a` + `include/`，约 60 MB）放回工程 `.pio` 库目录即可跨平台复用（同一 xtensa 工具链版本，Windows 链接正常）。之后 Windows 上 `pio run` / `-t upload` 正常。
- 只有 `serial` 传输的 `micro_ros_arduino` 也别指望：它只预编译了 `esp32`（对应 Arduino core 2.0.2），`src/` 里**没有 `esp32s3`**，也没有 Wi-Fi/UDP。
- 固件用的是 PlatformIO 版头文件 `micro_ros_platformio.h`（`micro_ros_arduino.h` 是 Arduino 库的头，别混）；`set_microros_wifi_transports()` 第 3 参是 `IPAddress`。

## 3. 官方 `QGP_EVMotor` 库进 PlatformIO

- 预编译归档是 `src/esp32s3/libqgpmotor.a`，`library.properties` 写了 `precompiled=true`；PlatformIO 只据此加 `LIBPATH`、**不加 `-l`**，而归档名 `libqgpmotor.a` 与库名 `QGP_EVMotor` 也对不上 → 直接引用会 `undefined reference to EMotionPI::begin()` 一类链接错误。
- 补一行即可（固件工程已配好）：

```ini
build_flags =
  -Llib/QGP_EVMotor/src/esp32s3
  -lqgpmotor
```

- 库内 NimBLE 占 341 文件 / 4.5 MB（蓝牙手柄用），micro-ROS 固件用不到，工程内置的是裁过的子集（`lib/QGP_EVMotor/`，0.86 MB，只留 `EMotionPI.h` + `ESP32Encoder.h` + `libqgpmotor.a`）。
- 电机驱动的实际用法与四个坑见 `docs/ESP32-S3电机驱动板资料.md` 第三节第 5 小节。

## 4. ESP32-S3 串口

- 板上两个 USB 口不一样：**USB-C 口**走 CH343 转串口（`VID:PID=1A86:55D3`），固件控制台在 UART0 / 115200，也是烧录口；另一个口是 ESP32-S3 **原生 USB**（`303A:1001`），固件不往 USB CDC 打印，接它看不到任何输出——不要据此判断板子坏了。详见 `docs/ESP32-S3电机驱动板资料.md` 第七节。
- COM 号不固定，用 `python tools/serial_monitor/serial_monitor.py --list` 确认。
- 打开 CH343 串口会经 DTR/RTS 自动复位电路让板子重启并打印 `ESP-ROM:esp32s3-…` 启动日志，属正常现象。
- **串口独占**：GUI 占着口时其它程序再打开会 `Access is denied`，先停 GUI。
- 只有一份「学而思编程助手」内嵌的 **esptool `3.0-dev`**：它能打开串口但**不支持 ESP32-S3 的 USB-JTAG**，表现为 `Connecting....` 后 `serial.serialutil.SerialTimeoutException: Write timeout`。要 `chip_id` / `flash_id` 得另装 esptool ≥ 4.x（`python -m pip install esptool`）。

## 5. Windows / PowerShell

- PowerShell 5.1 **不支持 `&&`**；用 `;` 或 `cmd1; if ($?) { cmd2 }`。
- **不要把中文路径写进 `.ps1` 文件**：UTF-8 无 BOM 的脚本会被按 ANSI 读取，生成乱码目录、文件落错位置（本项目踩过：`教学webppt` 变 `鏁欏webppt`）。中文路径改用 **bash 内联命令**（工具按 UTF-8 传入），或写成带 BOM 的脚本。
- 网卡操作用 `Get-NetAdapter | Where-Object { $_.ifIndex -eq <号> }` 管道传对象，不要用中文网卡名。`Restart-NetAdapter` / `Disable-NetAdapter` / `Enable-NetAdapter` 都不接受 `-InterfaceIndex`；`Get-NetAdapterStatistics` / `Get-NetAdapterAdvancedProperty` 只接受 `-Name` 或管道。
- 需要管理员的改动用 `Start-Process -Verb RunAs`（会弹 UAC）。
- **截 GUI 窗口不要用 `CopyFromScreen`**：窗口被其它程序遮挡时会拍到遮挡窗口。按窗口句柄用 `PrintWindow(hwnd, hdc, 2)` 抓最稳；句柄用 `Get-Process <exe> | Where-Object { $_.MainWindowHandle -ne 0 }` 取（后台进程返回的 pid 常是外层 powershell，其 `MainWindowHandle` 为 0）。
- 临时脚本放 `C:\Users\z\AppData\Local\Temp\kilo\`。

## 6. 网络可达性（下载源）

| 目标 | 是否可直连 | 说明 |
| --- | --- | --- |
| 奇果派 `www.7gp.cn` / `doc.7gp.cn` | 是 | 图片与文件可直接 `Invoke-WebRequest`，无需代理；个别直链会 404，按官网文章页核对 |
| GitHub API `api.github.com` | 是 | 稳定；抓仓库 README 用 `/repos/<owner>/<repo>/readme`（`Accept: application/vnd.github+json`），也可搜索仓库 |
| GitHub raw（`raw.githubusercontent.com`，已推送文件） | 不稳 | **多数请求 40 s 超时，重试 1–3 次才偶有 200**（`webfetch` 工具对该域名直接 `Transport error`）；请求加 `User-Agent`；未推送的文件链接返回 404 |
| 维特智能 `www.wit-motion.com`、地瓜机器人 `developer.d-robotics.cc` | 是 | 器件与规格页可直接抓（如 RDK X5 官方规格页） |
| 工创赛官网 `gcxl.edu.cn` | 否 | HTTPS 证书链不受信任，PowerShell 报「未能为 SSL/TLS 安全通道建立信任关系」 |
| `www.zdtmotor.com` | 否 | DNS 解析失败 |
| Docker Hub `registry-1.docker.io` | 否 | 需本机 Clash 代理（`allow-lan: true` + `mixed-port 7897`），见 `docs/ROS2与micro-ROS选型.md` 第四节 |
| PlatformIO 包存储 | 慢 | 可直连但单连接约 50 KB/s，改用 `tools/pio_mirror_seed.py` 预取 |

**不要用搜索引擎兜底**：Bing RSS（`?format=rss`）返回空 channel，Bing HTML 搜索中文关键词结果基本全是无关内容（2026-09 实测）。要抓资料就直接给官方页 / 已知 URL，或走上表的 GitHub API 与厂商站。

## 7. Python / 解释器

- `tools/pi.py` 依赖的 `paramiko` 装在**用户级 Python 3.14**（`C:\Users\z\AppData\Roaming\Python\Python314\site-packages`）；务必用 PATH 上同一个 `python` 运行，换解释器会 `ModuleNotFoundError: paramiko`。
- `tools/serial_monitor/` 依赖 `python -m pip install pyserial`（tkinter 随 Python 自带）。
- 复杂命令、含引号/括号/管道的命令写成纯 ASCII 的 `.sh`，用 `tools/pi.py --file` 执行（详见 `docs/树莓派连接与部署.md` 第四节）。
