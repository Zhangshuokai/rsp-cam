# docs

技术文档：设计原理、硬件参数、选型与部署记录。约定：一个主题一个 Markdown，文件名即主题，结论写在开头。

## 内容

- `设计原理流程图.md` —— 摄像头远程显示（`教学demo/摄像头远程显示/`）的程序设计原理、数据流与流程图。
- `树莓派连接与部署.md` —— 两台 Pi 的硬件/网络/账号对照、本机侧网卡、`tools/pi.py` 用法（含 `--put`）、常驻服务部署与排障（`教学webppt/树莓派连接与部署/` 的文字版，替代原先只在 `AGENTS.md` 里的连接细节）。
- `工作区结构与协作约定.md` —— 目录职责与归档去向、不入库清单、教学 webppt 的构建/折叠/图表/附件与下载地址约定、提交约定（`教学webppt/项目结构整理/` 的文字版）。
- `工具链与踩坑.md` —— PlatformIO 镜像加速、`micro_ros_platformio` 的 WSL 编库、`QGP_EVMotor` 链接参数、ESP32-S3 串口、PowerShell/中文路径与窗口截图、网络可达性等工具链坑合集。
- `摄像头参数.md` —— 新 Pi `zhangsk` 所用 USB 摄像头的硬件能力、可调控件与实测性能。
- `摄像头选型.md` —— UVC/CSI 协议对比与摄像头选型建议（含型号参考）。
- `ROS2与micro-ROS选型.md` —— 树莓派上 ROS 2 与 micro-ROS 的选型结论，在 `zhangsk` 上用 Docker 安装 ROS 2 Jazzy 的完整记录（含代理加速），以及 **micro-ROS 在本项目的落地记录**（Pi 侧 Agent 构建/启动、ESP32-S3 固件工程、DDS 默认域 0 的坑）。
- `ESP32-S3电机驱动板资料.md` —— 奇果派 S3 机器人控制板（ESP32-S3 电机驱动板）的硬件规格、接线、Arduino/Mixly/PlatformIO 开发、遥控器、物联网与 micro-ROS 对接资料汇总，含**实测**的两个 USB 串口差别、遥测格式、10 通道对应与 **QGP_EVMotor 电机驱动 API 实测配方**（来源 7gp.cn 专题 + 本项目实测）。

## 约定

- 硬件参数、选型、设计原理、部署记录放本目录；面向队员的讲义放 `培训/`。
- 涉及目标设备的操作细节（连接方式、网络配置、已踩的坑）以本目录为准：连接/网络/部署写 `树莓派连接与部署.md`，协作与 webppt 规范写 `工作区结构与协作约定.md`，工具链坑写 `工具链与踩坑.md`；`AGENTS.md` 保留同一份要点供会话直接读取，两处改动需同步。
