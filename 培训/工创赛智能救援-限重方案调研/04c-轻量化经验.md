# 轻量化经验手册（1.5kg 级救援机器人）

> 配套：`部件重量选型表.md`（数据）、`质量预算骨架.csv`（预算工具）｜采集 2026-09-28
> 适用目标：整机 ≤1.5kg（含软线）、300×300×200mm，需高速+避障+越障+对撞保护+推拨机构+全自主视觉。

## 一、总原则：先记账，再减重
1. **预算制**：任何零件进方案前先写进 `质量预算骨架.csv`；每加 10g，都要回答「从哪减 10g」。
2. **二八法则**：减重的大头永远在结构件（车体/支架）、轮系、电池三大块；传感器/小板卡再抠也只有几十克。
3. **称重纪律**：规格书的重量≠实物；**采购后逐一上秤回填**，打印件按切片预估×1.05；胶水、双面胶、扎带、标签按 20–30g 预留（经验值）。
4. 无人机界的减重心理价「**每克 1 元**」可作成本门槛参考（来源：壹倍达电调/电机二合一实测文）。
5. **CAD/切片预估 → 实秤修正**：同类限重赛事实测显示预估与总装实测差约 ±4%（1lb 项目：CAD 0.95lb→实测 0.91lb）。做法：全部零件先建表留估重，打印件用切片软件读克重，装配后整机上秤再把差值摊回各系统。

## 二、结构减重（见效最大）
1. **拓扑优化/掏料**：对承力件按受力路径留料，其余挖空。
   - 案例：波士顿动力 Atlas 腿部/关节支架经拓扑优化+碳纤维复材，较铝合金**减重 42–45%**；特斯拉 Optimus 躯干框架拓扑优化**减重 40%**（来源：51CTO 案例文、机器人大讲堂、x-techcon）。
2. **变厚度+加强筋**：平板件中间薄、边缘/孔位厚；用筋格替代实心，刚度损失小、重量降 30–50%（经验值）。
3. **一体化设计**：零件合并、减少紧固件和接插件。
   - 案例：RoboMaster 150g 格斗机器人底盘取消冗余卡扣、电机槽与底板一体；Optimus 一体化压铸把 200 件躯干件并成 3 件，**减重 30%**。
4. **低重心布局**：电池下沉到两轮轴之间/底盘最低处——同时改善越障时抗翻（相扑/搜救机器人通用法则）。
5. **圆角与倒角**：尖角既应力集中又难打印；圆角同时降低碰撞开裂（3kg 相扑 & 150g 格斗设计文均强调）。

## 三、材料替代（同体积减重比例）
| 从 → 到 | 密度比 | 同体积减重 | 备注 |
|---|---|---|---|
| 钢 7.85 → 铝 2.70 | 0.34 | −66% | 刚度退化，需补截面 |
| 铝 2.70 → 碳板 CFRP 1.6 | 0.59 | **−41%** | 工程首选，成本高 |
| PLA 1.24 → PA-CF 1.20 | 0.97 | −3%（但强度↑可镂空更多） | 打印件实际减重靠「可挖空」 |
| 铝 → 镁合金 1.7–1.8 | 0.65 | −35% | 需表面处理防腐蚀 |
| 金属 → PEEK 1.3 | — | 谐波减速器刚轮案例 −70% | 成本极高（约 30 万元/吨） |
- 案例：1X Neo Gamma 编织尼龙外壳、特斯拉 Optimus 大腿连接件 35% 玻纤 PA66（承 2000N 下减重 30%）；远想 PEEK 行星减速器 270g vs 金属 990g（**−73%**）。
- 对小车的现实选择序：**打印件选材（PA-CF/PLA+/PETG）＞亚克力/碳板混合 ＞铝件（只在轮轴座等关键位）**。

## 四、3D 打印减重技巧（最易落地）
1. **分区填充**：受力处 100%、非受力处 20–40%。案例：哈工深 RoboMaster 飞镖前端 100% 填充、后端 40% 调重心。
2. **壳体化**：大块实体全部改薄壳+内部支撑柱；有效材料系数（重量/实心重量）控在 **0.3–0.45**。
   - 换算示例：150×150×3mm PLA 平板实心 83.7g，系数 0.35 时仅 **29.3g**。
3. **层高/壁数**：壁 2–3 层、层高 0.24–0.28mm，兼顾强度与速度；非外观件不做实心顶底（顶底 3 层即可）。
4. **材料优选**：PLA（轻、硬、脆）/PETG（韧）/PA-CF（强韧，功能件）；预算允许时碳纤尼龙打承力件，比铝件轻、比 PLA 韌。

## 五、运动系统减重
1. **电机分级**：能用小不用大——N20 11g/台 vs 25mm 减速 100g/台，4 台差 ≈356g。
2. **高减速比换小电机**：低速大扭矩场景（推/拨）优先「小电机+高比齿轮箱」，而不是「大电机+低比」。
3. **无刷替代有刷**：2208 无刷 33–44g 可达 275–478W；同功率有刷 370 系 90–170g——**高速场景无刷赢在功率密度**，但需电调（+10–40g）。
4. **轮径与扭矩的平衡**：轮径大→越障好但扭矩需求↑；Ø65mm 是好折中（35–40g/个，实测数据）。
5. **编码器集成**：选自带霍尔/GMR 编码器的电机（如 JGB37-520、轮趣 MG513），省去外挂码盘 3–8g/台和走线。
6. **履带慎用**：整套履带底盘 ≥650g（不锈钢双层款），吃掉 43% 预算；麦轮 152mm 单只 2.85kg、轮毂电机单只 2.95kg——**直接出局**。

## 六、电池与供电
1. 能量密度：18650 ≈280 Wh/kg、21700 ≈257 Wh/kg ＞ 小 LiPo 101–146 Wh/kg。追求轻量+长续航优先圆柱电池组，但要自己配保护板与放电倍率（动力型 ≥10C）。
2. 小 LiPo 选型口诀：够用即可，容量每降一档减重 20–70g（850→450mAh 省 ≈50%）。
3. 分路供电：主控/传感器独立 LDO（小电池或 DCDC 支路），避免电机堵转拉低电压导致主控复位（废墟搜救机器人经验）。
4. 电池不可更换（本赛项规则）→ 按「单场时长×平均功耗」+50% 余量配容量，宁多 50g 不中途趴窝。

## 七、线材、紧固件、杂项（容易被忽视的 100g+）
1. 线材按总重 **4–8%** 预留（1.5kg 车 ≈60–120g）；短走线、取消杜邦线改 JST1.25/1.5 端子、共用电源总线。
2. 紧固件：M2/M2.5 尼龙螺丝/塑料柱替代钢螺丝（单颗省 0.5–1g，全车 60 颗可省 ≈40g）；能用卡扣/扎带不用螺丝。
3. 对撞保护：四角贴 TPU/泡棉缓冲（10–20g），比加厚整壳省得多。

## 八、检查清单（出图前自查）
- [ ] 每个系统行都有数字，合计 ≤1500g（含 20–30g 胶水杂项余量）
- [ ] 所有「估（低）」项已上秤核实或留了安全余量
- [ ] 打印件在切片软件里已按分区填充设定并导出重量
- [ ] 高速旋转件全为非金属（规则）、且无锋利外露
- [ ] 线材长度实测后剪短，端子数量最少化
- [ ] 电池容量满足「不可更换」的比赛全程 +50% 余量
- [ ] 四角有缓冲，推板/铲板可拆换
- [ ] 重心落在轮系支撑多边形内（越障时前移/后翻余量）
- [ ] 备件方案（备用推板/轮）重量也已计入（若随车）
