## —— 限重（≤1.5kg）条件下的合理方案研究

> **调研日期**：2026-09-28
> **面向**：2027 年第十届中国大学生工程实践与创新能力大赛（「智能+工程创新赛道」智能救援赛项）
> **赛程节奏**：校赛 2026 年秋 → 省赛 2027 年春 → 国赛 2027 年 7–8 月
> **资料来源**：官方发布稿《命题与运行 / 评分与规则》、官方《命题解析》（广东工业大学 于兆勤，51 页）、官方通知与附件（任务命题文档模板、设备及场地服务商）、多路网络调研（详见各节与附录）

## 0. 快读版（TL;DR）

- **赛项本质**：两台机器人同场对抗（各 3 分钟 / 3 分钟调试）；把场上救援目标**推/拨进本队安全区**得分——普通物资 5 分、核心物资 10 分、伤员 15 分；**禁止抓取、禁止载运**；**必须全自主**（不得以任何方式遥控）。
- **限重结构**：整机 **≤1.5kg**、出发投影 ≤300×300mm、高 ≤200mm（**含所有软线**）、全程单电源不更换——必须在 1500g 内同时解决「移动 + 感知 + 越障 + 推拨转运 + 碰撞对抗防护」。
- **本届三大变化**：① 取消「自主+遥控」选项 → **强制全自主**；② 新增**越障**要求，场地含障碍区与多种路面；③ 尺寸口径细化（软线纳入）、禁止与救援目标同色的装饰。
- **备赛窗口**：江西校赛 2026 年 10–11 月（即当下）；第十届启动及培训会已在**江西九江**召开；省赛场地器材由服务商**免费提供全套（含救援目标、围栏等）**。
- **下一步**：见 §6 行动清单（场地提供商/设备联系人、省赛联系人通道、任务命题文档 20% 的写法）。

## 2. 规则精读（2027「发布稿」+ 官方解析）

### 2.1 任务概述
- 每场同时上场**两队各一台**救援机器人；在保护自己免受对方干扰和碰撞的同时，把尽可能多的救援目标**转运至本队安全区**；必须适应现场环境。
- 机器人**必须采用自主运行模式**：允许与笔记本电脑通讯，但运行中不能触碰电脑、不得以任何其他方式遥控。
- 允许干扰对方，但**任何情况下不得主动进攻**。

### 2.2 机器人硬约束（限重为核心）

| 项目 | 要求 |
|---|---|
| **重量** | **≤1.5 kg**（整机） |
| **尺寸** | 出发时铅垂方向投影 ≤ **300×300mm**，高度 ≤200mm；**包括所有软质线路** |
| 外观 | 禁止误导性图案；**禁止与救援目标同色的装饰** |
| 电源 | **仅一块随车电源**（种类不限，禁液体/腐蚀性）；比赛全程（含调试）**不能更换电源** |
| 电子/零件 | 比赛过程中（含调试）**不能更换任何电子元器件与零部件** |
| 运行模式 | **全自主**；禁遥控（含任何无线遥控装置） |
| 功能要求 | 高速移动、避障、**越障**、目标搜索与转运、对象识别与信息获取（二维码/条码/文字/图像/形状/颜色/温度/振动等）、碰撞保护、失控保护 |
| 机械 | 方便拆装更换；结构须扛住碰撞/翻倒/跌落仍正常工作；**除行驶轮外**外露高速旋转件必须**非金属**；禁锋利结构 |
| **设计与制作** | 参赛作品须**自主设计制作**；除标准件外非标零件须**自主设计制造**，**不允许购买成品套件拼装**；救援机器人**机械部分自主设计制造**、方便拆装更换（官方原文） |
| 安全 | 禁伤害/易燃易爆机构；禁电子干扰设备；禁强光/激光等妨碍视线的发射器 |

### 2.3 场地（官方解析精确几何）

- 场地：**约 3000×3000mm** 正方形平面（以现场提供为准）；四周加固围栏（薄于 20mm、低于 100mm，非定位基准）。
- **出发区**：1–4 号共四个（洋红），抽签定；**出发区前有长方形减速带 3 根**（图解尺寸 **300×60×10mm**，间隔 50mm 摆放）。
- **安全区**（每队一个）：红/蓝两色抽签；面向场地一侧围栏截面为**直角三角**（斜面朝外，便于把目标从外面推入）；外包 **660×360mm**、内净 **600×300mm**；内部由 **20mm 隔板**分为**物资放置区 / 伤员放置区**（各半）。
- 中心区域摆放救援目标（初赛示意图：中心集中布置）。
- *口径差异提醒*：发布稿正文列「出发区、安全区、障碍区、各种路面和救援目标」，解析图页仅列「出发区、安全区、救援目标」——**以发布稿为准**，障碍区/路面细则盯补充通知与省赛文件。

### 2.4 救援目标

- 总量 ≤40 个；单体最大尺寸 ≤**140mm** 范围、重量 ≤**800g**（决赛现场公布新参数）。
- **初赛固定配比（20 个，3D 打印 ABS/PLA，允许色差）**：
  1. **普通物资**：绿色 40mm 正方体 ×8（图见官方解析 p40）
  2. **核心物资**：黑色 **正四面体** 40mm ×4（原文「正三棱锥」）
  3. **伤员**：橘色 **80×40×40mm** 长方体 ×4（单独转运、一次仅 1 个）
  4. **危险目标**：浅蓝 40mm 正方体 ×4（非救援目标，触碰红线）
- 三类救援目标均为双方**公共目标**（可抢）。

### 2.5 计分与红线（现场初赛 C，归一化 [本队平均分/全场最高平均分]×100）

**得分**：普通 5 分/个；核心 10 分/个；伤员 15 分/个（须**全部进入**安全区、不含围栏上）。

**主要规则点**：
- **首转规则**：必须先单独转运 **1 个普通物资目标**（多于 1 个无效）至本队物资区，之后方可转运核心/伤员。违者**本轮结束**。
- 单次转运物资目标 **≤3 个**（超 3 无效、本轮结束）；**伤员必须单独转、一次 1 个**（超 1 本轮结束）。
- 禁止抓取、禁止把目标放在机器人上（违者本轮结束）。
- 将目标移到对方安全区 → 计入对方；机器人进对方安全区（含压围栏）-5 分/次。
- 位置放错（物资↔伤员区互放，含围栏/隔板上）每个 -10 分并放回中心。
- **危险目标**移入安全区（含围栏上，不分红蓝）→ **本轮结束**；移出场地 → 本轮结束。
- 目标被撞出安全区：原有分数**不扣**、由裁判放回。
- 双方接触超 10 秒强制分离（回出发区，计时不中断）；**允许干扰、禁止主动进攻**。
- 一键启动后再次触碰作品（含电脑）→ 本轮结束；机器人停走 15 秒 → 本轮结束；失控 → 本轮结束；安全事故 → 取消后续资格。
- 每队抽签打 **2–3 场**，取平均成绩。

### 2.6 初赛三环节（总分 = A×20% + B×10% + C×70%）

1. **任务命题文档 A（20%）**：按官方模板（智能救援版=文件 4）提交；内容质量 75 分 + **排版规范 25 分**；雷同、出现校名/姓名/地名/电话等 → **0 分**；蓝色提示字未删扣分。
2. **作品创意设计 B（10%）**：创新性 40 + 美观性 30 + 合理性 30；同校外形雷同全 0。
3. **现场初赛 C（70%）**：见 §2.5。

### 2.7 决赛
- 创新实践（30%）：现场发布任务，用现场设备/材料（3D 打印、激光切割、PCB、数控、软件平台）完成设计制造；A/B/C 三等级（未用现场设备=C 等级取消后续资格）。
- 现场决赛（70%）：参照初赛流程，具体现场公布。

### 2.8 与 2025 版规则对比（对备赛最要命的变化）

| 项 | 2025（第九届） | 2027（第十届，现版） |
|---|---|---|
| 运行模式 | 自主 或 自主+遥控（首目标须自主） | **必须全自主**（可连笔记本但禁遥控） |
| 越障 | 未列 | **明确新增「越障」** + 多种路面 |
| 识别要求 | 「搜集与转运（除机械臂抓取）」 | **搜索与转运 + 对象识别与信息获取**（二维码/文字/颜色/温度/振动等） |
| 尺寸口径 | 「300mm 正方形、高 200」 | **300×300 含所有软线**；禁同色装饰 |
| 电源 | 未细节 | **单电源、全程不换** |
| 场地 | 2400 级、纯推球（2025 版） | **3000×3000**，目标/围栏/减速带全套新物 |

> 结论：**往届视频只可用于「构型参考」**——本届「全自主+越障+新场地」三项变化会让照搬老方案失效。

## 3. 限重设计空间分析

> 数据来源：B 站 2027 专题直播（厂商/培训机构口径，二手）+ 实机方案复盘 + 官方解析图读图。**克级数字未实物核验，正式 BOM 前须自测**。

### 3.1 两套底盘基准（直播「1.5kg 重量预算」表，逐项抄录）

| 项目 | 差速底盘基准 | 四麦轮底盘基准 |
|---|---|---|
| 电机+轮+驱动 | ~275g（电机+轮+万向球+驱动） | ~548g（M2006×4 + CNC 麦轮 + C610×4） |
| 电池 | ~150g（3S 850mAh 锂电） | ~85g（6S 850mAh 75C 锂电） |
| 主控/算力 | ~50g（STM32F407 + ESP32-S3） | ~80g（RK3588S + STM32F407） |
| 传感器/其他 | ~65g（摄像头+线束+电机座） | ~115g（D435i + OV5640 + ToF×2 + IMU + 光电门×4） |
| 结构/外壳 | —（并入底盘合计口径） | ~220g（结构+线束+外壳） |
| **底盘合计** | **~540g** | **~1048g** |
| **剩余给机构/外观/裕量** | **~960g** | **~452g** |

- 排序原则：**电池 → 电机 → 计算 → 传统结构**；材料建议 **PLA-CF / PETG-CF**、拓扑优化、结构-功能一体化。
- 主控逐级增重：+K230（~15g）→ +RK3566（~35g）→ +RK3588S（~60–80g）→ +Pi5+Hailo（~80–110g）。

### 3.2 子系统选型（直播共识 + 对标交叉）

- **驱动**：差速（JGB37×2+TB6612 ~210g 最轻最快成车）vs 四麦轮（M2006×4+C610 ~428g）。关键差异不在重量而在**对位能力**：麦轮可 vy+ω 双向平移（IBVS 收敛约 0.4s），差速只能 vx+ω 螺旋逼近（约 1.5s）→「预算受限首选差速，追求投放精度/效率选麦轮」。
- **算力阶梯**（重量/功耗/价格）：

| 级别 | 型号 | 算力 | 重量 | 功耗 | 价格 |
|---|---|---|---|---|---|
| MCU | STM32F407 / ESP32-S3 | — | 10–18g | <1W | ¥25–60 |
| 轻量 NPU | K230 CanMV / RK3566 | 0.5–1T | 10–35g | <3W | ¥80–250 |
| **中 NPU★** | **RK3588S / Rock 5B** | **6 TOPS** | **55–75g** | 5–10W | ¥350–650 |
| GPU | Jetson Orin Nano | 40–100 TOPS | ~100g | 7–15W | ¥1800+ |
| 轻视觉栈（对标） | 树莓派5 + Hailo-8L + YOLOv10s | — | ~80–110g | — | — |

- **传感器矩阵**：RGB-D D435i（VIO 定位+围栏检测）；广角 OV5640（铲口/颜色复核）；IMU ICM-20948（6 轴 200Hz）；ToF VL53L1X ×4–6（避障/安全区对位）；对射红外光电门 ×2–4（通过计数）；可控补光。
- **定位三方案**（精度/重量/成本三角）：

| 方案 | 精度 | 重量 | 成本 |
|---|---|---|---|
| 雷达+陀螺+反光柱/单目 | <10mm | ~188g | ~¥800 |
| D435i + 单目广角 | <20mm | ~90g | ~¥2500 |
| K230 单板全栈（视觉） | <30mm | ~50g | ~¥200 |

- 感知验收口径（直播）：**危险目标误判 = 0；绿色识别召回 >95%**。
- **对标修正（公开实证，2026-09）**：省一 / 国一队伍实际采用**端侧 NPU 模组**——MaixCAM Pro + YOLOv8-INT8（省一实测 **mAP50 96%、链路 29.98 FPS**，350→900 图即可训出）、K230 CanMV；重算力（RK3588/Jetson）亦有获奖先例，但「树莓派」被国一作者点名劝退（YOLO 帧率低、限制车速）。**限重下「端侧 NPU」是重量与性价比双优解**。

### 3.3 转运机构流派（禁抓取/禁载运约束下）

- **对标落点（主推）**：**双舵机「框式拨具」（可抬起）**——张开/闭合/抬起/放下（coo7-lang 已验证范式；BUCEA ★49 获奖机实物同为框式拨具 + 9g 金属齿舵机）。**「可抬起」因 2027 新规则从「锦上添花」变为「得分必需」**：安全区被 **20mm 隔板**分为物资区/伤员区、**错区每个 -10 分**，纯固定推板难以把目标「挑」进指定半区。
- **直播推荐**：「贯穿式自适应通道（地面导流式）」~115g——前段导向铲（入口 100mm、被动滚轮）/ 中段波纹壁（自适应 25–85mm）/ 后段可控闸门（舵机、投放 <0.03m/s、光电门确认）；**目标贴地滑行、靠通道壁约束**。铲口默认抬起，视觉确认才降铲；**遇危险目标不降铲、直接绕行**。
- 其他流派：夹爪式 ~80g（**与禁抓取红线冲突，仅列不采**）；旋转扫臂 ~120g（直播不推荐：可控性差）。
- 实机所见流派：履带+大弧面推铲（BV1cKRVYUEmq）／齿轮驱动弧形拨片（BV15mhb6QEjs、BV1R1YE6FEec）／环状托料盘兜推（BV1R1YE6FEec）。
- **合规边界（重要）**：规则原文「禁止抓取救援目标及将救援目标放置在机器人上」；涉及"抬离地面/暂存"的边界设计**赛前书面报裁判确认**，主推"推、拨、导流"三类无滞留动作。

### 3.4 越障与减速带

- 减速带：3 根、官方解析图读数 **300×60×10mm**、间隔 50mm，出发区正前方（起步即连续跨越）。
- 通过性配置：差速用 **Φ65mm 橡胶轮（有实车验证：Nsea261168「能越过减速带、推动所有物块」）+ 后辅助轮 + 万向球**；麦轮方案用「板簧+扭力梁」悬架（直播）。速度策略：减速带区降速通过、直线段加速。
- 「障碍区/各种路面」细则在两份官方文件中口径不一（发布稿含、解析图未列），**以发布稿为准并盯补充通知**；机构/底盘预留通过性余量。

### 3.5 对抗防护与程序红线（限重下的强度分配）

- 结构须扛**碰撞、翻倒、跌落**（对撞与 10 秒强制分离机制背景下）：优先「框架+缓冲角+低重心」而非全面装甲；电气防缠绕（线束全收纳于轮廓内；**软线计入尺寸检查**）；**对抗防护不靠配重**（配重直接吃掉重量预算，官方规则只要求"仍能正常工作"）。
- 程序红线：一键启动仅一次机会、启动后未离出发区本轮结束；停走 15 秒结束；失控（含危险目标误触）结束；**禁止主动进攻（允许干扰）**。
- 预算平衡点（草案）：底盘 540–1050g + 机构 100–200g + 结构外壳 150–250g + 线束紧固 50–100g + 裕量 100–200g。

### 3.6 三档配置草案（与 `mass/` 部件表配套）

## 5. 推荐方案方向（给备赛团队的落地建议）

> 基于 §2 规则、§3 限重空间、§4 对标；**分阶段递进**，每阶段都可独立上场拿分。

### 5.1 总原则
1. **合规优先**：一切动作为「推、拨、导流」——不抓取、不载运、不滞留；边界设计赛前书面报裁判。
2. **重量预算先行**：先电池→电机→算力→结构，机械/结构件最后做且全程称重；全局预留 **15–20% 重量裕量**（对抗碰撞件、配重、备用传感器）。
3. **简单可靠 > 花哨**：3 分钟全自主、一键启动、无人干预；**任何故障 = 0 分**，冗余与降级设计比性能更重要。
4. **先成车、再升级**：差速 + 推铲最快成车；确认得分闭环后，再按预算升级麦轮/算力/机构。

### 5.2 三阶段路线

| 阶段 | 目标 | 配置要点 | 预估重量 |
|---|---|---|---|
| **一、基础得分**（2–4 周） | 过减速带、把普通物资推入安全区 | 四轮差速 + Φ65mm 轮 + 前推铲 + STM32 + K230/MaixCAM 视觉（五类识别）+ 极简状态机（首转 1 普通 → 批量 ≤3） | ~0.9–1.1kg |
| **二、稳定得分**（1–2 月） | 得分动作稳定 + 红线不碰 + 分区分投 | 加**框式拨具（可抬起，双 9g 舵机）**；单轴陀螺仪定绝对 0°；安全区斜坡推入与「物资/伤员分区」投放策略；程序保护（15s 停走/失控）；防卡防缠绕 | ~1.1–1.3kg |
| **三、高分竞争**（进阶） | 速率/精度/对抗 | 底盘精调（差速升级悬架/轮系，或评估三轮全向；**麦轮谨慎**——有超重淘汰先例）；端侧 NPU 提频或 RK3588 按重量预算评估；通道式导流 / 多段拨具；IBVS 对位；**目标调度优化（分值组合最大化 + 干扰对方存量）** | ~1.3–1.4kg |

### 5.3 关键决策点（按公开实证修正）

| 决策 | 选项 | 建议 |
|---|---|---|
| 底盘 | 四轮差速 / 四麦轮 / 履带 | **首推差速**（有实车+获奖实证，过减速带验证）；麦轮有整车超重淘汰先例、慎选；全地形可评估履带 |
| 算力 | MCU / K230·MaixCAM / RK3588 / Jetson / 树莓派 | **首推 MaixCAM Pro·K230 端侧 NPU**（省一国一实证、最轻）；RK3588 进阶；树莓派劝退（帧率低限车速） |
| 定位 | 端侧视觉 / D435i / 反光柱雷达 | 视觉定位起步（单轴陀螺仪定绝对 0°）；D435i 90g 加成；反光柱雷达最高精度但 188g |
| 转运机构 | 推铲 / **框式拨具（可抬起）** / 通道式 / 摆臂 | **推铲打底 + 框式拨具主推**（分区投放必需）；通道式为进阶；摆臂不推荐 |
| 电池 | 3S（~150g）/ 6S 75C（~85g） | 按电机选；**单电源、全程不可换**——容量按 2–3 场 + 调试耗电规划 |

### 5.4 训练与自测清单（按规则红线逐项回归）
- 减速带×3 连续通过率（≥95%）；
- 五类目标识别混淆矩阵：**危险目标误判 = 0**、绿色召回 >95%；
- 状态机回归：首转单个普通 → 批量 ≤3 → 伤员单独 1 个 → 全程不碰危险目标；
- **分区投放精度**：物资进物资区、伤员进伤员区（错区 -10 分/个）——框式拨具「抬起+入区」动作专项测试；
- 对抗演练：被推挤后的恢复、10 秒接触分离后的再启动、**不越界对方安全区（-5 分/次）**；
- 一键启动 / 断电恢复 / 2–3 场连打耐久（单电源全程）；
- **场地**：联系服务商或省组委会拿标准训练场（含四类目标/围栏/减速带）；或按 3000×3000 + 660×360 三角围栏自建 1:1 训练场。
