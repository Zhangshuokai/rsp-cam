## 是什么

对「只选一个机器人入门复现项目 → 优先『抓取方块』」这条路线做的一份**实测评估**：先用 Robotics Toolbox 跑 FK/IK 与末端轨迹，再用 Swift 可视化，之后迁移 MuJoCo / ROS 2，最终接 VLA。结论：值得，评级 A-，是当前条件下的最优单一入门路线。

评估方式不是读文档对比——整理者在本机把 L1（Toolbox FK/IK）与 L2（Swift 完整抓取-放置动画）全流程跑通，并把 Swift 2.0 的四个坑（`headless` 语义、约 10 秒握手窗口、单客户端纪律、无头截图姿势）踩完记录在案。

## 读法与注意事项

1. 先读主件的「一句话结论」与第一节评分表，再看第二节实测记录。
2. 第五节「坑清单」可直接写进讲义；第六节的命令是按整理者本机路径写的（`~/.hermes/bin/uv`、`~/projects/robot-entry-recon/smoke/`），**脚本未随包分发**，照抄前先按自己的环境改路径。
3. L3 的 MuJoCo 在整理者本机是 QEMU 虚机（CPU 无 AVX2）导致 SIGILL，属环境限制而非路线问题；物理机正常。
4. 对外讲解用 `教学webppt/机器人入门复现路线/`（deck 成品 `index.html`，可离线双击）。
