# 培训

面向队员的培训资料与赛项解读。约定：一份材料一个 Markdown，文件名即主题。

## 内容

- `赛项.md` —— 智能+工程创新赛道（智能分拣 / 智能搬运 / 智能救援）规则速记、计分与红线对比。
- `工创赛智能救援-限重方案调研/` —— 由外部整理的「智能救援」限重（≤1.5kg）方案调研包 v1.0（2026-09-28）：主件调研报告、B 站/文献判读笔记、部件重量选型表与质量预算、轻量化经验、官方核实与行动清单，另附 `图集/`、`官方原件/`。先读其中的 `README-交付说明.md`，主件为 `00-调研报告（主件）.md`。

## 约定

- 讲义、培训提纲、规则解读、评分要点放本目录。
- 与实现强相关的内容（程序设计、硬件选型）放 `docs/`，不要与培训材料混放。
- 由外部代理整理、自成体系的整包调研资料（含官方原件与图集）可整体落一个子目录，在其 `README` 里说明结构与读法，不逐文件拆散。
