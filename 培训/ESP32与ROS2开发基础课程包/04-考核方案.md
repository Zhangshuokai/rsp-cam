# 《ESP32 与 ROS 2 开发基础》考核方案

> 原则：**能力本位、过程为主、当堂验收**。职业本科强调"做出来才算会"，
> 因此不设期末闭卷笔试，成绩来自每一次动手与最终作品。

## 一、成绩构成

| 考核项目 | 比例 | 说明 |
|---|---|---|
| 平时表现 | 20% | 考勤 5% + 课堂任务 10% + 团队协作 5% |
| 实验考核 | 40% | 11 次实验当堂验收 + 实验记录 |
| 综合项目 | 40% | 方案 10% + 功能演示 20% + 答辩与报告 10% |
| **合计** | **100%** | 60 分及格 |

## 二、平时表现（20%）

| 项目 | 分值 | 评分要点 |
|---|---|---|
| 考勤 | 5 | 全勤得满分；迟到一次扣 0.5；无故缺勤一次扣 2；缺勤超过 1/3 按学籍规定处理 |
| 课堂任务 | 10 | 每次课的 ⭐ 验收点完成情况，累计计分（少一次扣 1） |
| 团队协作 | 5 | 与搭档的分工与互查；能主动帮助他人、共享排障经验 |

## 三、实验考核（40%）

每次实验满分 4 分（11 次共 44 分，按 40 分折算；缺做按 0 分计，补做满分 3 分）。

| 评分项 | 分值 | 评分标准 |
|---|---|---|
| 功能验收 | 2.5 | 当堂完成全部验收点；演示流畅、结果可复现 |
| 实验记录与问答 | 1.5 | 记录完整（含失败与解决）；能正确回答 1–2 个原理问题 |

**加分项（每次最多 +0.5，总分不超过 40）**：
- 主动复现并解决一个他人遇到的故障，且在记录中给出"现象—假设—验证—结论"；
- 完成课堂拓展任务（如实验九的 `PING/PONG` 扩展、实验十一的界面改进）。

**实验评分表（教师用）**

| 实验序号 | 功能验收(2.5) | 记录问答(1.5) | 加分 | 总分 | 备注 |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| … | | | | | |

**缺勤与补做**：因故缺勤须在一周内找开放时段补做，补做成绩封顶 3 分；未补做记 0 分。

## 四、综合项目（40%）

### （一）项目要求

每组 2–3 人，从 [02-教学单元设计.md](02-教学单元设计.md) 第 15 周的题目 A–E 中选题（自拟须审核），并满足：

1. **必须包含**：板端样式控制 + ROS 2 话题通信（控制台/脚本任选一种交互方式）；
2. 至少一个**自己扩展**的功能点（新指令、新界面控件、双板协同逻辑等）；
3. 现场演示 + 答辩；
4. 提交项目报告（模板：需求 → 方案图 → 实现要点 → 测试与问题 → 分工与贡献）。

### （二）评分构成

| 项目 | 分值 | 评分主体 |
|---|---|---|
| 项目方案 | 10 | 教师 |
| 功能实现与现场演示 | 20 | 教师 70% + 其他组互评 30% |
| 答辩与报告 | 10 | 教师 |

### （三）项目量规（总分 40）

| 维度 | 优秀（90–100%） | 良好（75–89%） | 合格（60–74%） | 待改进（<60%） |
|---|---|---|---|---|
| 功能完成度（12 分） | 全部计划功能 + 至少 2 个自扩展功能，链路稳定 | 全部计划功能，偶有需重试 | 核心功能可演示 | 核心功能不完整 |
| 技术难度（6 分） | 双板协同/序列编排/自定义协议，方案合理 | 单板多样式 + 话题控制 | 基础指令控制 | 仅点亮灯 |
| 稳定性（6 分） | 连续演示 3 分钟无掉线，异常可自恢复 | 偶发需手动复位 | 能完成一次演示 | 演示多次失败 |
| 创新与体验（6 分） | 有明确用户视角的改进（提示、状态、操作流畅） | 有一定体验设计 | 界面/交互可用 | 无交互设计 |
| 答辩与报告（10 分） | 原理清晰、分工明确、报告规范、能回答追问 | 能说明实现与问题 | 基本说明做什么 | 说不清自己做了什么 |

### （四）互评表（组间，每项 0–5 分）

| 评分项 | 组 1 | 组 2 | … |
|---|---|---|---|
| 功能是否有意思、演示是否清楚 | | | |
| 稳定性（是否一次成功） | | | |
| 讲解是否听得懂 | | | |

> 互评去掉一个最高分和一个最低分后取平均；互评分数差异超过 30% 时以教师评分为准。

## 五、等级与学术诚信

- 总评 ≥90 优秀、80–89 良好、70–79 中等、60–69 及格、<60 不及格。
- 以下行为当次成绩记 0：抄袭他人代码且不能解释、实验记录编造数据、项目报告虚构分工。
- 允许并鼓励查阅官方文档、开源代码与同学讨论，但**必须能解释自己提交的每一行代码**。
