# 《ESP32 与 ROS 2 开发基础》课程标准

## 一、课程基本信息

| 项目 | 内容 |
|---|---|
| 课程名称 | ESP32 与 ROS 2 开发基础 |
| 课程性质 | 专业基础课（理论实践一体化） |
| 适用对象 | 职业本科一年级（电子信息、物联网、机器人、智能制造、计算机等专业） |
| 学分 / 学时 | 3 学分 / 48 学时（16 周 × 3 学时） |
| 先修课程 | 计算机应用基础；建议与《Python 程序设计》同期或其后开设 |
| 后续课程 | 嵌入式系统、传感器技术、ROS 2 机器人开发、物联网系统集成 |
| 教学场所 | 机房/实训室（Windows 学生机 + WSL2 环境 + 无线局域网 + 每 2 人一组开发板） |

## 二、课程性质与定位

本课程是面向职业本科大一学生的**软硬件协同入门课**。课程不追求芯片底层与算法理论的深度，
而是以"**会装、会写、会连、会调、会做**"为目标，通过一个贯穿全程的真实项目——
**双板 LED 协同控制系统**（两块 ESP32-S3 通过 WiFi 接入 WSL 中的 ROS 2，实现 LED 控制与协同），
让学生建立三个层次的完整认知：

1. **设备层**：微控制器如何运行程序、控制硬件（GPIO / WS2812 / 串口）。
2. **通信层**：设备如何组网并交换数据（TCP、自定义行协议、心跳与重连）。
3. **系统层**：嵌入式设备如何融入机器人软件框架（ROS 2 节点、话题、桥接、人机界面）。

课程采用**项目导向、任务驱动、现象先行**的教学组织方式：每次课先让学生看到"现象"
（灯亮了、消息通了、页面动起来了），再解释背后的原理，最后落到一个可验收的小任务。
所有代码与工程流程来自仓库中的真实项目，学生完成的不是"玩具作业"，而是一个可扩展的
小型物联网/机器人通信系统原型。

## 三、课程目标

### （一）知识目标

1. 说出 ESP32-S3 的主要特性，解释 GPIO、数字输出、WS2812 可寻址 RGB 的基本概念。
2. 说明 MicroPython 程序的运行机制（固件、REPL、`boot.py`/`main.py`、设备文件系统）。
3. 描述 TCP 客户端—服务器通信的基本过程，理解 IP/端口/心跳/断线重连的作用。
4. 理解自定义行协议（`HELLO`、`DATA`、`STYLE`、`PLAY`、`MIX` 等）的设计方法。
5. 说出 ROS 2 中节点、话题、消息、工作空间、功能包的基本概念及 `colcon build` 的作用。
6. 解释顺序轮播与并行混合（时间合成）的基本思想及"最小采样间隔"的意义。

### （二）能力目标

1. 能独立检测串口、擦除并烧录 MicroPython 固件，会阅读板载串口日志定位问题。
2. 能编写并部署 MicroPython 程序，控制板载 RGB 的颜色、亮度、闪烁周期与常亮/闪烁模式。
3. 能使用工具脚本完成代码的模块化组织与一键部署。
4. 能在 WSL 中构建 ROS 2 工作空间，使用 `ros2 topic` 命令行收发、查看话题消息。
5. 能读懂并小幅修改桥接节点与板端协议解析代码，增加一条自定义指令并完成联调。
6. 能按小组完成"需求→方案→实现→演示→答辩"的完整工程闭环。

### （三）素质目标

1. **工程严谨**：按"硬件→固件→网络→中间件→应用"的分层方法定位故障，形成可复用的排障思路。
2. **协作沟通**：两人一组、明确分工，能进行任务拆分、代码互查与结果汇报。
3. **安全合规**：具备密钥保护、最小暴露面、开源许可与设备安全用电意识。
4. **自主探究**：遇到失败先复现、再定位、后求助；能利用日志与官方文档解决问题。
5. **职业认同**：通过国产芯片与开源生态的真实案例，建立对嵌入式/机器人行业的兴趣与信心。

## 五、课程思政元素与融入点

| 教学单元 | 思政元素 | 融入方式 |
|---|---|---|
| 1 | 科技自立自强、国产芯片 | 介绍乐鑫（Espressif）作为全球 Wi-Fi/蓝牙 MCU 领先厂商；对比"卡脖子"背景，讨论国产芯片与开源固件的产业价值 |
| 2–3 | 工匠精神、规范意识 | 代码规范、命名与模块划分；"第一次部署失败不是板子坏了"——先复现再定位 |
| 4–5 | 网络安全、保密意识 | `wifi_config.py` 密钥不入库、不投屏；服务只监听本机地址；理解"最小暴露面" |
| 5–7 | 系统思维、团队协作 | 用分层图讲清"设备→网络→中间件→应用"；小组排障时分工与信息同步 |
| 8–9 | 实事求是、质疑求证 | "一颗灯能否同时播放多种样式？"——从物理限制到时间复用方案，体验"先证可行、再算代价、后实现" |
| 10–11 | 用户意识、精益求精 | 界面反馈不误导用户（在线状态、保存不覆盖）；缓存 Bug 的复盘 |
| 综合项目 | 职业素养、诚信与版权 | 项目分工与互评；引用开源代码需遵守许可（MicroPython MIT、ROS 2 Apache-2.0） |

## 六、教学条件与资源配置

### （一）硬件（每组）

| 设备 | 数量 | 说明 |
|---|---|---|
| ESP32-S3 N16R8 开发板 | 2 块 | 分绿板/蓝板，板载 WS2812 RGB |
| USB 数据线 | 2 根 | 必须支持数据通信（非仅充电线） |
| 无线路由器 / 手机热点 | 1 套 | 2.4 GHz；独立局域网，不与办公网混用 |
| 计算机 | 2 台 | Windows 10/11，安装 Python 3.10+ 与 WSL2 Ubuntu 24.04 |

### （二）软件（学生机镜像）

- Python 3.10+ 及 `esptool`、`mpremote`（`python -m pip install esptool mpremote`）
- WSL2 + Ubuntu 24.04 + ROS 2 Jazzy（预装或离线镜像）
- 可选 THONNY（厂商资料目录中提供安装包，便于初学者交互式验证）
- 代码仓库：本仓库（`common/`、`green/`、`blue/`、`tools/`、`ros2_ws/`）

### （三）资源

- 厂商资料：`ESP32-S3开发板N16R8焊接/`（例程、MicroPython 固件、Flash Download Tool、Thonny）
- 课程仓库文档：`AGENTS.md`（环境与命令速查）、`course/`（本课程包）
- 延伸阅读：MicroPython 官方文档、ROS 2 Jazzy 官方教程（docs.ros.org）
