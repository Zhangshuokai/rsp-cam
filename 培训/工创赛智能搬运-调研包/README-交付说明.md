1. **`00-调研报告（主件）.md`**：先看 TL;DR 与「推荐方案 v1.0」，建立全局认知（约 15 分钟）。

9. **`02-B站对标-清单与抽帧.zip`**：44 条候选清单 + 抽帧拼图，先看图选视频，再按链接去看原片。
