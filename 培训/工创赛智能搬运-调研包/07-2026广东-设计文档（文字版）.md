## 一、结构设计

### 1、设计概述
面向 2026 年广东省「智能物流搬运」赛项：具备物料识别、精准抓取、稳定搬运与可靠码垛能力的全向移动机器人。全流程：二维码任务读取 → 原料区圆形物料定位与颜色识别 → 抓取搬运 → 码垛区精准放置。

总体技术路线：**STM32F407ZGT6 底层运动主控 + D-Robotics RDK X5 视觉处理**；**三自由度圆柱坐标（RPP）机械臂 + 麦克纳姆轮全向底盘**；整机 4mm 碳纤维板为主体，关键件 PETG/ABS 3D 打印。

### 2.1 总体结构布局
自下而上四层：**底盘行走层 → 电控与供电层 → 机械臂操作层 → 视觉感知层**（分层独立拆装调试、降低干涉）。
- 底盘：麦轮四轮独立驱动，**O 型安装**（纵向/横向驱动力解耦，横移平稳精度高）
- 机械臂：**RPP 构型**（旋转云台 R + 升降 P1 + 水平推送 P2）；正逆解为线性系、三关节互不耦合、圆柱工作空间天然适配转盘布局
- 视觉：**双 USB 摄像头**——底盘侧端扫二维码（侧向），机械臂上端认物料（下向、随臂运动）；图像由 RDK X5 跑 OpenCV，结果串口发 STM32

### 2.2 底盘系统
- **4mm 碳纤维板**框架（加工误差 ≤0.1mm）：固定基准板（底板）+ 上层安装板 + 3mm/2.5mm 铜柱；M3/M2 螺丝+法兰盘固定。基准板承担：四轮共面基准 / 电路模块承载 / 机械臂云台底座接口 / 电池槽+物料盘+走线通道
- PCB 位于基准板下方约 20mm，铜柱支撑，层间走 DC/USB/XH2.54 线
- **四轮各一个带 CAN 通信的 42 步进电机**独立驱动（编号 1-4 逆时针），**CAN 菊花链 + 两端 120Ω 终端电阻**（焊于 PCB 集成板）
- 底盘集成：STM32F407ZGT6 最小系统、RDK X5、集成 PCB、指示面板、**串口屏**、12V 5000mAh 锂电池、**20KG 舵机圆形物料盘**

### 2.3 机械臂（RPP 三自由度）
- **R 旋转云台**：35KG 舵机直驱立柱底座，范围 ≥270°（覆盖取料区+码垛区）
- **P1 升降**：42 步进（编号5）驱动 **480-2GT 同步皮带 + MGN7 直线导轨**；行程约 100mm；对比丝杆：无回差、低噪、免润滑；上下机械限位挡块
- **P2 水平推送**：35 步进（编号6）驱动**齿轮齿条**；行程约 80mm；平推电机初始位置需手动标定（主动齿轮缺口为基准、左偏两齿）
- **末端夹爪**：35KG 舵机平行开合爪，指面贴防滑橡胶/硅胶，适应直径 30-50mm 圆形物料；夹爪供电独立开关（可单独断电应急复位）

### 2.4 加工与连接
碳纤维板数控雕刻/激光切割；PETG/ABS 打印传动件；标准件（铜柱/M3/M2/法兰盘/DC 线/XH2.54/USB）。走线原则：供电与信号分离、沿框架边缘走、运动关节留活动余量。

## 二、控制系统设计

### 1、控制思路
**「STM32F407ZGT6 + RDK X5」异构架构**，USART1（9600bps）定长帧协议调度。

**（1）运动控制**：CAN 总线（PA11/PA12，500Kbps 扩展帧）驱动 **6 路 ZDT_X57 步进**——1-4 麦轮底盘、5 升降、6 平推。麦轮公式 `V1=+Vx+Vy-W, V2=-Vx+Vy+W, V3=-Vx+Vy-W, V4=+Vx+Vy+W`；位置系数 **X 轴 10.5 转/mm、Y 轴 10.3 转/mm**；**WHT101** 陀螺仪 Yaw 反馈；TIM4 50ms PID（**Kp=2, Ki=0.05, Kd=0.4，积分限幅 7**，±180° 归一化）。

**（2）末端执行器**：TIM2 三路 PWM——夹爪（PA2，**6°夹紧/60°张开**）、物块转盘（PA3，**120°步进三工位**）、云台（PA1，7V）；**五阶平滑插补 `s=6τ⁵-15τ⁴+10τ³`** 消除启停冲击。

**（3）视觉**（RDK X5 + 双 1080P USB 摄像头）：二维码 PyZBar + **3 帧一致性验证**；物块 **HoughCircles（r=35-45px）+ HSV 三通道面积投票**（红双阈值 H[0-10]+[160-180]、绿 H[35-89]、蓝 H[90-140]）；判稳双阈值：**位置偏移<10px 连续 30 帧 + 颜色置信度 ≥70%**；色环两级精度：**640×480 粗定标（系数 1.18，±5mm）→ 1920×1080 精定标（系数 0.29，±2mm）**。

**（4）通信**：STM32→X5 单字节 ASCII（**14 条指令**）；X5→STM32 定长包 `0xFF+9字节+0xFE`，三级状态机中断接收；「请求-响应-确认」三层握手。

**（5）中断优先级**：USART1（0/0，接收 X5）→ TIM4（PID 50ms）→ TIM5（OLED+IMU 500ms）→ TIM6（微秒延时）→ EXTI0（PA0 复位重启 X5）。

### 2、主要器件选择
1. **STM32F407ZGT6**（Cortex-M4 168MHz，排母插接便于更换）
2. **D-Robotics RDK X5**（10 TOPS，8 核 A55，Ubuntu 22.04，双摄接入）
3. **ZDT_X57 步进 + CAN**（CAN 转 TTL，500Kbps 扩展帧；每路独立地址；位置/速度/力矩多模式）
4. **35KG 数字舵机 ×3**（夹爪 PA2 / 转盘 PA3 / 云台 PA1）
5. **WHT101 九轴 IMU**（USART2，Z 轴校零，50ms 周期）
6. **双路 1080P USB 摄像头**（上=物料/色环/码垛，下=地面二维码，V4L2）
7. **CAN 转 TTL + 蓝牙预留**（UART5；国赛禁用无线，未使用）；USART6 串口屏
8. **3S 12V 锂电 + 多路降压**（12V 电机 / 8.4V 舵机 / 5V 主控与 X5，5V1 隔离舵机干扰；9000mAh 续航约 3 小时，<10.5V 更换）
9. **OLED + 串口屏 + LED**（0.96 寸 OLED 显示 IMU 角度；LED 状态：慢闪=就绪）

## 三、程序流程说明
上电 → STM32 初始化全部外设；X5 systemd 自启 Python 视觉程序 → 发握手包 `987654321` → STM32 LED 快闪=上位机就绪。
按启动键（PC9）→ IMU Z 轴校零 → **指令 '1'** 触发扫码（下摄，PyZBar 解 7 位任务码如 `132+231`）。
底盘移动至物料区 → **指令 '2'** 首次物块定标（HoughCircles+HSV→坐标+颜色码）→ 底盘微调对准。
转盘旋转后 → **指令 '3'** 转向判断+位置排序（C2 与 C1 对比判转向，扫三工位用排他法推算抓取位置索引）。
依次抓取三物块（每次抓取前 **'5'/'6'** 验证到位且颜色正确）→ 穿越通道至色环区。
色环两步定位：**'7'** 640×480 粗定标（±5mm）粗调 → **'8'** 1920×1080 精定标（±2mm）精调 → 按颜色逐个放置。
第二圈同流程（`a/4/b/c`）→ **'9'** 码垛区高位堆叠 → 底盘归位，任务完成。全程 **14 条串口指令严格时序**。
