## 一、规则原文口径（补齐 03）

依据 `官方原件/搬运-官方原文分节合订.txt`（附件 2-1 / 2-2 原文）逐条核对：

- **运行时间**：两轮，每轮 **调试 3 分钟 + 运行 3 分钟**；官方原文「每轮运行时间 3 分钟」。课程口径的 240 秒与此一致，按官方 3 分钟执行。
- **区域尺寸**（官方表 2）：启停区 300×300 mm；原料区顶面 **φ300 mm、总高 80–100 mm**；暂存区 / 粗加工区 **580×150 mm**。
- **圆环**（官方表 3；φ 为物料最大直径，圆环线宽 1.5 mm）：外径 1 环 `φ+3`、2 环 `φ1+5`、3 环 `φ2+7`、4 环 `φ3+10`、5 环 `φ4+10`、6 环 `φ5+10`；分数 15 / 10 / 7 / 5 / 3 / 1，6 环外或物料倾倒 0。
- **放置判定**：以「**垂直方向能否看到该环外圈**」判环号；**物料底面触地即放置完毕**，之后再移动该物料本轮结束；把物料在场地推行移动，结束比赛。
- **任务码**：四组三位数、以「+」连接；颜色编号 红1 黄2 蓝3 绿4 黑5 浅蓝6；二维码板 A4 横放、码面 80×80 mm（含边框）。
- **违例**：越出灰色车道（机械臂除外）、停止 15 s（等待转盘 +8 s）、发令后触碰机器人（含笔记本）或物料、自行取出掉落物料 → 本轮结束；原地高速打滑裁判可终止；结构 / 尺寸不符 → 成绩无效。

## 四、决赛（补齐）

- 环节与权重：**创新实践 D 30% + 现场决赛 E 70%**；`D = D1 工程效益 + D2 技术能力 + D3 综合素质 − 扣分`（安全 / 诚信 / 纪律）。
- **A / B / C 等级**：A = 用现场设备 / 材料 / 软件平台完成任务并在后续任务中应用；B = 完成但未应用；C = 没用现场平台完成 → **取消后续决赛资格**。
- 现场决赛流程参照初赛，两轮取最好；决赛区域 / 物料 / 形式 / 尺寸及相关参数**现场公布**。

## 六、通信协议基线（自广东实车提取）

- 串口 **9600 8N1**（`/dev/ttyUSB0`）；帧 `0xFF + 9 字节 ASCII + 0xFE`，不足补 `0x00`。
- 命令（单字节 ASCII）：`1` 扫码、`2`/`a` 定首个物块、`3`/`4` 转盘排序、`5`/`6`/`b`/`c` 抓取位确认、`7` 色环粗定标、`8` 色环精定标、`9`/`0` 码垛、`d`–`i` 决赛成品区 / 固定物料区、`r` 重启；就绪 / 确认回 `987654321`。
- 摄像头：下 `/dev/video0`（扫码）、上 `/dev/video2`（物块 / 色环 / 码垛）；依赖 `opencv-python`、`numpy`、`pyserial`、`pyzbar`（系统库 `libzbar0`）。
- 安装与权限：`sudo apt install -y python3-opencv python3-numpy python3-serial libzbar0` → `pip3 install pyzbar`；`sudo usermod -aG dialout,video $USER` 后重登。

## 八、关键器件规格（联网核对）

- **上位机 RDK X5**（地瓜机器人官方规格页，2026-09-28）：8×A55@1.5 GHz、BPU **10 TOPS**、GPU 32 Gflops、4 / 8 GB LPDDR4、2×4-lane MIPI CSI、4×USB3.0、1×CAN FD、Wi-Fi6 + BT5.4、Ubuntu 22.04、85×56 mm、5 V/5 A。对照：树莓派 5 / Jetson Orin Nano 亦可，取舍在「算力 vs 惯量」。
- **闭环步进（ZDT X42S / X57，Emm 固件；`xhfb/emm_stepper` 手册 V1.0.5）**：串口 TTL / RS485、115200、多机不同地址（1–255）；速度模式 0–6000 RPM；位置模式默认 16 细分下 **3200 脉冲 = 1 圈**；回零支持就近 / 方向 / 无限位碰撞 / 限位开关；**堵转检测与保护**，可读位置 / 速度 / 电流 / 温度；支持广播同步。
- **航向传感器**：HWT101（单轴航向角）与 WHT101（九轴）同族；公开工程用 115200 / 230400，用于锁航向与麦轮「车身漂移」。
- 其他（J60-Z27 爪、3M 同步带、麦轮、无极 S2 主控）**无权威公开参数页**，以到货实测与课程原表为准。
