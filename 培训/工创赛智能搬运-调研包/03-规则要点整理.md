> 用途：备赛 / 教学 / 方案设计的事实底本。本稿为**结构化提取**，条款以官方发布稿原文为准（原件见 `official/`）。

## 0. 先看这里（TL;DR）

- **智能搬运 = 智能+工程创新赛道三赛项之一**（智能搬运 / 智能分拣 / 智能救援）。
- **不设整机限重！** 限制的是**尺寸：铅垂投影 ≤300×300mm、高 ≤400mm**（含所有软线；机械臂可折叠、出发后自行展开且展开后不限）。
  → **对比：智能救援是 ≤1.5kg 限重**——两个赛项的硬约束正好相反，别记混。
- **必须抓取 + 载运**：抓 1 个放到机器人上，才能抓下一个；**不允许用爪夹持着物料运送**。
  → **对比：智能救援禁抓取、禁载运，只能推/拨。**
- 任务主线：读二维码拿「任务码」→ 原料区电动转盘抓 3 色物料 → 按序放粗加工区圆环 → 转运至暂存区圆环 → 第二批 → 暂存区**码垛** → 回启停区显示统计。
- 计分：初赛总成绩 **P = 任务命题文档 20% + 作品创意设计 10% + 现场初赛 70%**。
- 场地 **2400×2400mm** 工业场景，灰色十字车道（宽 400mm），**越出车道即本轮结束**。

## 1. 作品硬约束（附件2-1 · 一）

| 项 | 要求 |
|---|---|
| 定位 | 低能耗智能搬运机器人；**自主设计制造**；除标准件外**非标零件须自研**；禁成品套件拼装 |
| 运行 | **完全自主**；允许与笔记本通讯（运行中不得触碰）；**禁任何遥控** |
| 补光/遮挡 | **仅允许垂直向下补光；禁对场地遮挡** |
| 显示装置 | 上部醒目位置**任务码显示**（亮光、不被任何物体遮挡、**字高 ≥12mm**），能显示任务码+完成情况 |
| 电源 | **仅一块内置电源**，全程（含调试）不可更换 |
| 传感器/电机 | 种类与数量不限 |
| 尺寸 | 投影 **≤300×300mm**、高 **≤400mm**（含所有软质线路）；机械臂可折叠，**出发后方可自行展开，展开后尺寸不限**；不符即取消资格 |
| 重量 | **发布稿未设整机重量限制**（※以现场检录为准） |
| 机械 | 行走方式、机械臂形式不限；比赛中（含调试）不得更换任何零部件 |
| 启动 | **「一键式」启动**：唯一「启动」按钮、明确标识、不被遮挡；每轮只有一次启动机会 |

## 2. 场地（附件2-1 · 一）

- **2400×2400mm** 正方形；**灰色行车道**（中间十字车道宽 **400mm**）；四个淡黄色区 450×450；其余亚光白。
- **黑色模拟障碍物 φ50×100mm**，数量与位置随机抽签。
- **启停区 ×2**（蓝色，300×300；出发位抽签 1 或 2）。
- **原料区**：电动转盘（φ300、高 80–100mm；**6–10 秒/圈**；转向任意；每转停留次数/时间现场为准）；一次放 **3 个**物料（呈 120°）；**两批物料颜色一致**。
- **粗加工区 / 暂存区**：各 **580×150mm**，表面有**圆环 1–6 环**与数字标识，放置位置每轮**抽签**决定。
- 精加工区、成品区（决赛涉及，细节现场公布）。
- **二维码板**：A4 横放，码面 80×80mm（含边框），位置随机。

## 3. 物料与任务码（附件2-1 · 一）

- 物料：3D 打印 **ABS / PLA**；**≤80mm、≤100g**；初赛为**回转体**。
- 颜色 6 种：**红1 黄2 蓝3 绿4 黑5 浅蓝6**（红黄蓝绿黑=ABS，浅蓝=PLA）；每色 2 个；**抽签定三种（同形状）**；现场可能有色差。
- 决赛物料形状/颜色变化（圆柱、方形、三角形、球体、锥体、组合体等，以现场为准）。
- **任务码 = 4 组三位数**（以「+」连接）：
  - 第 1 组：第一批 3 个物料的**颜色与搬运顺序**；
  - 第 2 组：第一批在**粗加工区+暂存区**的放置位置；
  - 第 3 组：第二批 3 个物料颜色与顺序；
  - 第 4 组：第二批在**粗加工区**的放置位置。
  - 例：`156+123+516+231` → 第一批依次红/黑/浅蓝，分别放粗加工区与暂存区的 1/2/3 号圆环；第二批黑/红/浅蓝放粗加工区 2/3/1 号圆环。

## 4. 现场初赛流程（附件2-1 · 一 + 解析）

1. **检录**：测尺寸、查显示装置等；抽签场地号与出发位。
2. **调试 3 分钟**（不得更换零件）；剩 **1 分钟**抽签搬运任务（**第二轮重新抽签**）；剩 **30 秒**机器人停放启停区，转盘上料、插好二维码板。
3. 统一发令 → **一键启动**（一次机会，不启动即本轮结束）。
4. 到二维码板**读码** → **显示任务码**（无法清晰辨认不得分）。
5. 原料区**按任务码顺序逐个抓取**：抓 1 个、放上机器人，才能抓下一个。
6. 携物料**沿车道**至**粗加工区**，按序放入对应圆环（**底面触地即放置完毕**）。
7. 把粗加工区物料再装车 → 运至**暂存区**按序放入（第一批平面放置）。
8. 返回原料区 → 第二批 3 个物料重复流程。
9. 第二批在暂存区**码垛**：放在第一批之上，**颜色一致 + 第一批正确 + 不掉落**才得分。
10. 完成全部流程回**启停区**，显示装置显示**抓取/放置正确数量**。
11. 每队**两轮**（各 3 分钟调试 + 3 分钟运行），取最好成绩。

## 5. 计分（附件2-2 · 一）

| 分项 | 分值 |
|---|---|
| 正确读码并在显示装置显示任务码 | **1** |
| 每正确抓取 1 个物料（抓到 + 放上机器人） | **2** |
| 圆环放置（非线性）：1/2/3/4/5/6 环、环外或倾倒 | **15 / 10 / 7 / 5 / 3 / 1 / 0** |
| 暂存区码垛（第二批，色一致+平稳） | 同第一批分档 |
| 按时回启停区 | **2** |
| 显示抓取数、放置数 | **各 2** |

- 现场初赛 **C = 100 ×（本队得分 / 最高得分）**；初赛总 **P = A×20% + B×10% + C×70%**。
- **A 任务命题文档**（100）：内容质量 75 + 排版规范 25；**雷同 / 含校名地名姓名电话 = 0 分**。
- **B 作品创意设计**（100）：创新性 40 + 美观性 30 + 合理性 30；**同校外型雷同 = 0 分**。
- **决赛**：D 创新实践 30%（工程效益 D1 + 技术能力 D2 + 综合素质 D3 − 扣分）+ E 现场决赛 70%；总分分 **A/B/C 等级**（未用现场平台完成任务 = C 级，取消后续资格）。

## 6. 红线（比赛规则，附件2-2 · 一）

- 两轮各 **3 分钟调试 + 3 分钟运行**；发令后不得再接触机器人（含笔记本）或物料，否则本轮结束。
- 出发后**必须在灰色车道行驶**：任何部分铅垂投影越出车道（机械臂除外）→ 本轮结束。
- **停止运行 15 秒**→ 本轮结束（等待转盘增 8 秒）。
- **物料触地即定分**；再移动该物料 → 本轮结束；**掉落物料不得自行取出**（取出即结束）。
- 原地高速打滑：裁判可终止比赛（按打滑前成绩计）；损坏场地取消资格。
- 结构/尺寸/参数不符：不得参赛或成绩无效。

## 7. 与「智能救援」对照

| | 智能搬运 | 智能救援 |
|---|---|---|
| 形态 | 单机任务赛（速度+精度） | 双机对抗赛 |
| 硬限 | 尺寸 300×300×400mm；**无重量限制** | **≤1.5kg**；尺寸 300×300×200mm |
| 操作 | **抓取 + 载运**（不许爪持运送） | **禁抓取/禁载运**（推/拨） |
| 场地 | 2400×2400 工业场景 | 3000×3000（含越障） |
| 得分 | 读码1 / 抓取2 / 圆环15-1 / 码垛 / 回位2 / 显示2；P=20+10+70 | 目标 5/10/15；错区 −10；满分 140 |
| 难点 | 视觉识别 + 抓取机构 + 圆环精度/码垛 + 路径规划 | 限重 + 越障 + 推拨机构 + 对抗防护 |
