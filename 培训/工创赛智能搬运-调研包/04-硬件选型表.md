## 二、选型原则（课程与原话）

1. 「轮距正方形，尺寸尽量大，接近但不超出极限值」（出发 300×300 内）〔第 22 集对照表〕
2. 「减速是必须的，不要轻易尝试电机直驱」〔清单表备注〕
3. 「一次抓一个，放到小车上之后才能抓下一个」〔规则对照表〕
4. 摄像头分工：720P 认二维码、1080P 认物料颜色〔对照表〕
5. 供电：**只能使用一个电池且装在小车内部**；方案 = 2S 航模锂电池〔对照表〕
6. 控制：上位机树莓派、下位机无极 S2〔对照表〕
7. 车板件优先「CNC/钣金/碳纤维」，追求刚度；爪具「先稳定后优化」

## 三、采购与替代建议

- **主渠道**：课程原表淘宝链接（网盘包内 Excel 第二列链接）；同款见「一点创绘」店铺/工创社区店。
- **备选参考**：往年开源车 BOM（满环车 GitHub / 国特 CSDN 文章内有清单）——件级别可交叉比价。
- **不买可打印的**：机械爪安装件、屏幕支架、部分轮毂件可 3D 打印（课程明确）。
- **训练件**：地图+物料+电动转台建议早买（训练周期最长）；色差注意（不同批次/自打印件会有色差，决赛物料现场公布）。
- **全局定位模块（J75）**：课程时点未上架，可用「陀螺仪 + 视觉 + 编码器融合」替代（对应第 17 集方案）。
