## 这是什么

针对「智能+搬运」赛项的完整调研交付包：**官方规则 + B 站全量对标 + 开源方案 + 推荐方案与硬件选型表**。为备赛（校赛 2026 秋 → 省赛 2027 春 → 国赛 2027 年 7–8 月）提供一套「可抄作业」的底座。

## 怎么用（建议阅读顺序）

1. **00-调研报告（主件）**：先看 TL;DR 和「推荐方案 v1.0」，建立全局认知（15 分钟）
2. **03-规则要点整理**：规则/流程/计分细节（与官方文件对照阅读）
3. **04-硬件选型表**：采购与自制件清单（含课程原始备注与替代建议）
4. **05-配套资料索引**：网盘/GitHub/课程/官方渠道怎么找
5. **02 ZIP（B站对标清单与抽帧）**：44 条候选清单 + 68 张抽帧拼图——先看图集选感兴趣的视频，再按链接去 B 站看原片
6. **图集/**：22 张关键高清帧（物料清单表、夹爪、电机、底盘、场地图等）
7. **官方原件/**：发布稿、51 页命题解析、2025 名单、服务商通知等
