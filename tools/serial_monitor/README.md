# 串口波形监控（serial_monitor）

桌面 GUI：把串口里以逗号分隔的数值行按通道画成实时波形，同时保留原始输出。默认面向奇果派 S3 板（ESP32-S3）每 ~500 ms 一行的 10 个数值状态包。

## 依赖

- Python 3（本仓库用 PATH 上的 `python`，3.14）
- `pyserial`：`python -m pip install pyserial`
- `tkinter` 随 Windows 版 Python 自带，无需安装

## 运行

```
python tools/serial_monitor/serial_monitor.py
python tools/serial_monitor/serial_monitor.py --port COM9 --baud 115200 --autostart
python tools/serial_monitor/serial_monitor.py --demo          # 模拟数据，不占用串口
python tools/serial_monitor/serial_monitor.py --list          # 列出串口后退出
```

参数：`--port`（如 `COM9`）、`--baud`（默认 `115200`）、`--window`（波形窗口点数，默认 `300`）、`--autostart`、`--demo`、`--list`、`--names`（逗号分隔的通道名，按 `c0,c1,…` 顺序）。

## 通道定义（当前遥控器）

| 通道 | 名称 | 通道 | 名称 |
| --- | --- | --- | --- |
| `c0` | `ch1` | `c5` | `swb-6` |
| `c1` | `ch2` | `c6` | `swc-7` |
| `c2` | `ch3` | `c7` | `swd-8` |
| `c3` | `ch4` | `c8` | `vra` |
| `c4` | `swa-5` | `c9` | `vrb` |

默认即按上表命名（`DEFAULT_NAMES`），换遥控器/换顺序用 `--names` 覆盖，例如：

```
python tools/serial_monitor/serial_monitor.py --names "ch1,ch2,ch3,ch4,swa-5,swb-6,swc-7,swd-8,vra,vrb"
```

波形区每条泳道默认是「通道名 + 大号当前值」，泳道够高时再补一行 min ~ max。通道数在第一次收到数值行时自动确定。

## 界面（示波器风格）

> 字号按工业 HMI「实时曲线」板的比例放大：**通道名与当前值同为 24 pt 粗体**（名用通道色、值用白色，投屏可读），标题 22 pt，控件与日志 13 pt，辅助行 11 pt；默认窗口 1500×950。

- **标题栏**：`SERIAL SCOPE` + 运行指示灯（`RUN` 绿 / `PAUSE` 琥珀 / `IDLE` 灰）+ 实时指标（设备、波特率、样本速率、显示通道数、帧数、字节数）。
- **控制条**：端口下拉（蓝牙端口排最后）、波特率、窗口点数、`运行/停止`、`暂停`、`清空`、`导出 CSV`、`逐通道`（恢复被点掉的通道）、`隐藏日志`。
- **屏幕区**：细/粗两级栅格（粗线每 5 格）、右侧 `now` 触发参考线带三角标记；每个通道一条泳道，自动定纵轴范围，带荧光描边的实时折线 + 最新样本点。
- **通道徽标（左侧）**：色点 + 通道名 + **大号当前值**（24 pt 粗体）；泳道高度足够（≥ 56 px，例如隐藏日志或放大窗口）时，额外在下方给出「原始下标 `cN` + 窗口内 min ~ max」，不够高就只显示名+值。**单击徽标可隐藏/显示该通道**（隐藏后变灰）。
- **鼠标悬停**：显示垂直游标 + 读数框，列出该样本位置所有通道的值（含相对最新样本的偏移）。
- **时间轴**：按测得速率换算成秒（`-15.9s … now`）；速率未知时退化为样本数。
- **底部状态栏**：数值行数、通道数（显示数）、窗口点数、快捷键提示、最近一行原始数据（超长截断）。
- **日志区**：非数值行（如 `setup`、ROM 启动日志）只进日志，不画波形；可折叠。

### 快捷键与鼠标

| 操作 | 作用 |
| --- | --- |
| `空格` | 暂停 / 继续（画面冻结，串口仍在收） |
| `Esc` | 运行 / 停止串口 |
| `Ctrl+S` | 导出 CSV |
| `Ctrl+L` | 显示 / 隐藏日志 |
| 悬停屏幕 | 垂直游标 + 各通道读数 |
| 单击通道徽标 | 隐藏 / 显示该通道 |

## 与硬件的关系

- 硬件侧的完整实测记录（两个 USB 口的差别、ROM 启动日志、遥测格式、10 通道对应、供电）见 `docs/ESP32-S3电机驱动板资料.md` 第七节「串口调试与实测遥测」；本工具就是它的配套上位机。
- 要点：奇果派 S3 板的 **USB-C 口**经 CH343 转 UART，固件控制台在 **UART0 / 115200**（`COMx`，本机实测 `COM9`）；另一个口是 ESP32-S3 原生 USB（`VID:PID=303A:1001`），固件没往 USB CDC 打印，**接它看不到输出**。
- 打开串口会触发 CH343 的 DTR/RTS 自动复位，板子会重启一次并打印 ROM 启动日志，属正常现象。
- 数值行形如 `992,992,1376,992,992,192,192,992,1126,924`（10 个值，对应上表 `c0…c9`）。通道数在第一次收到数值行时自动确定；某一行数值个数少于已有通道数时，该行只进日志。

## 说明

- `导出 CSV` 导出的是当前窗口内缓冲的样本，各通道按到达顺序对齐，表头用通道名。
- 通道名默认按当前遥控器定义（见上表），换遥控器/换顺序用 `--names`。
