# 课程教材编写标准

面向配套**课程教材**（Word / 活页式讲义与 `docs/` 文字版）：与 `编写守则.md` 的 PPT 侧标准呼应，规定教材侧的图文配置与记忆友好要求。两套标准同源，冲突处理见第七节。

制定依据：多媒体学习认知理论（Mayer：多媒体、空间/时间邻近、一致性、信号、分段原则）；职业本科认知特点（图形、流程、类比记忆优于成段文字）。

---

## 一、读者与目标

- 读者：**职业本科**学生（高考约 300–400 分段）。抽象阅读负担高，靠图、表、类比接收更快。
- 目标：**以图为纲助记**——让学生先记住图（骨架），再由图复述知识；不靠逐字背诵概念与基础理论、公式与推导。
- 教材是 deck 的文字版承载：与 deck 同源、不删减，图示两处保持一致。

## 二、图文配置（每个知识点）

- **每个知识点（小节）至少 1 张配套图**：截图＋标注，或流程图 / 结构图。
- **「操作步骤类」必须配流程图**：一步一个节点，按真实顺序画；纯文字步骤清单不能单独成节。
- **纯理论概念配「类比图解」**：把抽象定义映射成学生熟悉的事物或场景（生活化类比、示意插图）。
- 图要交代「看什么」：正文给出一句话导读指向该图（见第五节）。

## 三、记忆锚

- **每章至少 1 个记忆锚**，四类任选其一以上：口诀 / 生活化类比 / 场景化案例 / 颜色编码。
- 记忆锚要在**图表中重复出现**强化：正文讲一次、图里再标一次，颜色 / 图标全章统一。
- 例：把「采集 → 编码 → 传输 → 显示」压成口诀，并在流程图上按同一顺序、同一配色标注。

## 四、禁止 ASCII 字符画

- 与 `编写守则.md` 同口径：流程 / 结构 / 架构一律用**真实图形**（截图、矢量图、` ```mermaid `）；**不得**用 `─` `│` `┌` `└` `├` `┐` `┘` `▼` 等符号在正文或代码块里拼图。
- **排版中不得用字符拼图**：箭头、分栏、方框示意都用真实样式；目录结构用嵌套列表，层级用真实排版层级。
- 交付前 `grep` 框线字符，**命中数必须为 0**；有命中即不合格，返工为图。

## 五、图与文对齐

- **图注编号连续**：按章 / 节统一编号（如「图 3-2」），不跳号、不重号。
- **正文有指代**：正文用「如图 3-2 所示」明确指到具体图，禁止无正文引用的孤图。
- **一句话导读**：每张图给一句「看什么 / 说明什么」，放在图注或正文首句，读者先看图注就能懂大意。

## 六、版式

- **题注样式统一**：图题在图下、表题在表上，字体 / 字号 / 编号格式全册一致。
- **一图不超过半页时并排**：A4 用双栏或图文并排，减少空页与跨页断裂。
- **打印友好**：黑白打印仍可辨——不单靠颜色区分关键信息（颜色之外给线型 / 标注兜底），线宽足够、对比明确。

## 七、与《编写守则》的关系

- **PPT 侧以 `编写守则.md` 为准，教材侧以本文为准**；两文同源，图示与要点保持一致、互不删减。
- **冲突时**：以求真、可图化、助记优先——宁可少字多图，不用长文字堆概念。
- 教材改动与 deck 改动同步；细节口径（点式动画 ≤3 处、成品无外链、桌面 / 手机校验断言等）仍见 `编写守则.md` 第四、七节。
