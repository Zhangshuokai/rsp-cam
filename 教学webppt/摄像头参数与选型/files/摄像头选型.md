# 摄像头选型与协议参考

> 结论先行：**当前这颗已经是 UVC 摄像头**（`uvcvideo` 驱动、`Found UVC 1.00 device HD camera 349c:2317`、USB 2.0）。
> “换 UVC 摄像头”不会带来提升——UVC 是**协议标准**，不是画质档次。真正决定清晰度/帧率的是传感器、镜头、快门、接口带宽。
> 型号清单来源：Arducam 官方 UVC 产品线（网页检索，规格以商品页为准）。

## 一、当前摄像头现状

| 项 | 值 |
| --- | --- |
| 名称 | `HD camera`（Generic） |
| USB ID | `349c:2317` |
| 协议 | **UVC 1.00**（驱动 `uvcvideo`） |
| 总线 | **USB 2.0**（480 Mbps） |
| 分辨率上限 | 1280×960 MJPG / 640×480 YUYV |
| 帧率上限 | 25 fps |
| 对焦 | 定焦（无 `focus_*` 控件） |
| 快门 | 卷帘（普通 webcam） |
| 已知日志 | `Failed to resubmit video URB (-1)`（偶发流中断可能与此有关） |

瓶颈是**传感器分辨率 + 定焦镜头 + USB2 带宽**，不是 UVC 协议。

## 二、协议对比

| 协议 | 走线 | 在 Pi 上的访问方式 | 优点 | 缺点 |
| --- | --- | --- | --- | --- |
| **UVC**（USB Video Class） | USB | `/dev/video0` + OpenCV `CAP_V4L2`（免驱） | 即插即用、跨平台、控制项标准、可换任意 USB 摄像头 | 受 USB 带宽限制（USB2 需 MJPG，留延迟）；镜头/传感器参差 |
| **CSI + libcamera**（MIPI） | 排线 | `picamera2` / `libcamera`（非 `/dev/video0`） | 硬件 ISP、低延迟、官方传感器质量稳定 | OpenCV 需经 `picamera2` 转换或 GStreamer `libcamerasrc`；只有官方/兼容模组 |
| GMSL / 工业接口 | 同轴 | 专用驱动 | 长线、抗干扰、多路同步 | 贵、需采集卡，竞赛场景过剩 |

> 注：厂商常宣传的“UVC 3.0”并非官方标准版本号，通常只是指 **USB 3.0 的 UVC 摄像头**；UVC 官方版本为 1.0 / 1.1 / 1.5，越高支持的分辨率/压缩格式越多。

## 三、选型必须看的六个维度

1. **分辨率 / 像素尺寸**：不仅看多少 MP，也看单像素大小（低照度）。
2. **对焦方式**：定焦 / 手动(M12·C·CS 可换镜头) / 自动对焦(AF)。近距离读小字必须能对焦。
3. **快门**：卷帘（rolling，运动有果冻效应）vs **全局快门（global）**（高速运动必备）。
4. **帧率 / 延迟**：25fps 够看画面；抓取/闭环控制要低延迟 → USB3 + 非压缩 YUY2。
5. **视场角与景深**：读码/分拣常用 70–110°；C/CS 口可配镜头调景深。
6. **接口带宽**：USB2 只能 MJPG；USB3 可跑未压缩。

## 五、按赛项场景的建议

- **智能分拣 / 读二维码、颜色形状**：工作距离固定 → 定焦即可，优先**分辨率 + 光源**；要拍清小字选可换镜头（M12/C 口）或 AF，例如 `B0459 IMX477 12MP`、`B0474 IMX708 12MP`。
- **智能搬运 / 移动底盘**：有运动 → 优先**全局快门**（`B0499 IMX296`、`B0385 OV9782`）避免拖影。
- **智能救援 / 弱光环境**：优先大像素低照度（`B0496 IMX462`、`B0200 IMX291`、`IMX708`）。
- **需要低延迟闭环**：USB3 的 UVC（YUY2 无压缩，如 `B0471/B0474`）或官方 CSI + picamera2。
- **预算优先且要免驱**：任意标准 UVC 摄像头（现在这颗就是），把精力放在**光照 + 固定对焦距离**上，往往比换硬件提升更明显。

## 六、给当前项目的具体建议

1. 协议不变（继续 UVC/V4L2 + OpenCV），**不需要为“协议”换摄像头**。
2. 若继续用现在这颗：锁定**固定工作距离 + 补光**，能解决大部分“看不清”。
3. 若要升级，按需求二选一：
   - 要**防运动模糊** → 全局快门 UVC（IMX296 / OV9281 / AR0234）；
   - 要**拍清小字/近距对焦** → 电动对焦或 M12 可换镜头 UVC（IMX477 / IMX519 / IMX708）。
4. USB3 摄像头可让 Pi 5 走 USB3 口 + 未压缩格式，延迟更低（现在的 USB2 只能 MJPG）。
